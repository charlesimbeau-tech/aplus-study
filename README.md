# A+ Study

An ADHD-friendly study app for the CompTIA A+ exams (220-1201 Core 1 and 220-1202 Core 2).

Live: https://charlesimbeau-tech.github.io/aplus-study/

Every exam objective is a checkpoint on a map. The "Next up" button always points at the one thing to do now. Progress is saved in your browser.

## Development

```sh
npm install
npm run dev
```

Pushing to `main` builds and publishes the site automatically (see `.github/workflows/deploy.yml`).
